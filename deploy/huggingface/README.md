# OpenAtlas

Watch every NASA SPHEREx exposure of any spot on the sky, blink them like a
flip-book and find what moves. Built by team dreamlyfters for the NASA Space
Apps Challenge 2026.

Source code: https://github.com/freedomwarriorx86/dreamlyfters_OpenAtlas
(GNU AGPL-3.0-or-later).

This Space is deployed from `deploy/huggingface/` in that repository with
`python deploy/huggingface/deploy.py <user>/<space>`.
